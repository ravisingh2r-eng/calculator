✅ Include.js Working

Yeh page demonstrate karta hai ki header aur footer partials kaise load hote hain include.js ke through.

How It Works

  • Page load hone par include.js automatically run hota hai
  • Yeh script data-include attribute wale elements dhundhta hai
  • Specified HTML file fetch karke element me inject karta hai
  • Scripts jo partial me hain woh bhi execute hote hain

Usage Example

<!-- Header include karne ke liye -->
<div data-include="/partials/header.html"></div>

<!-- Footer include karne ke liye -->
<div data-include="/partials/footer.html"></div>

<!-- Include.js load karo (body ke end me) -->
<script src="/assets/js/include.js"></script>

Features

  • Vanilla JavaScript - No jQuery or other dependencies
  • Caching - Partials cache hote hain for better performance
  • Error Handling - Failed loads show error message
  • Events - Custom events fire on load/error
  • Script Execution - Inline scripts in partials work correctly

Note: Local file system par test karne ke liye local server chahiye (CORS restrictions ki wajah se). Use: php -S localhost:8000

Advanced Usage

// Manual reload all partials
PartialInclude.reloadAll();

// Clear cache
PartialInclude.clearCache();

// Listen for load complete
element.addEventListener('partial:loaded', function(e) {
    console.log('Loaded:', e.detail.url);
});
